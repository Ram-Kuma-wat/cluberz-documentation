# Module 15: My Favourites

## Purpose

Allow users to save preferred venues and events for quick access.

## Features

- Add/remove favourites from listings and detail pages
- Quick access to saved venues and events from the My Favourites tab
- Saved items retain their latest availability, pricing, and status
- Saved list cards show venue/event name, thumbnail, location, and key pricing/rating
- Card click opens the relevant club, restaurant, or event detail page
- A checked favourite icon remains visible on each card to remove from favourites
